## 1. Opus 5 — новая модель по умолчанию в Claude Code (релиз 2.1.219)

**Зачем.** Тем, кто ежедневно работает в Claude Code: сменилась дефолтная модель, а с ней — цена/качество каждого запуска и поведение сабагентов. Знать это нужно до того, как удивишься счёту или новой глубине вложенности.

**Как.** Обнови до `2.1.219+` (`claude update`). Opus 5 (`claude-opus-5`) становится дефолтным Opus: 1M контекст, `/fast` теперь применяется к Opus 5 и 4.8 ($10/$50 за Mtok против базовых $5/$25). Сабагенты теперь могут порождать вложенных сабагентов до глубины 3 (было 1) — отключить `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1`. Добавлены хук `DirectoryAdded` (после `/add-dir`), настройка `sandbox.network.strictAllowlist` и показ ошибок MCP-подключений в `/mcp`.

**Подвох.** На Max/Team Premium/Enterprise дефолт переключился сам; на Pro/Team Standard остаётся Sonnet 5. Вложенные сабагенты глубиной 3 удобны, но незаметно умножают расход токенов — следи за лимитами.

`cost-tokens · subagents` · Источник: [docs/Anthropic](https://code.claude.com/docs/en/changelog#2-1-219)

## 2. Opus 5 подменил ваш дефолт: как проверить версию и закрепить модель и effort

**Зачем.** Если у тебя Max/Team Premium/Enterprise — модель могла смениться без твоего ведома, а прежний уровень effort сохранился (в т.ч. `low`, если ты его когда-то ставил ради экономии). Стоит перепроверить, иначе результат и счёт «поедут».

**Как.** Проверь версию: `claude update` → `claude --version` (нужно ≥ 2.1.219). Закрепи модель явно: `/model claude-opus-5`. Посмотри и при нужде сбрось усилие: `/effort` (текущее), `/effort auto` (дефолт модели = high). Цена за токен та же ($5/$25), выигрыш — в стоимости за задачу и меньшем разбросе между прогонами.

**Подвох.** На Pro/Team Standard дефолт остаётся Sonnet 5 — Opus 5 включается только вручную (`/model opus`). Материал — сторонний tips-блог, не официальная документация; сверяйся с офиц. changelog.

`cost-tokens · tips` · Источник: [blog/wmedia.es](https://wmedia.es/en/tips/claude-code-opus-5-default-model)

## 3. Opus 5 в Claude Code: как выбирать effort и fast-режим под задачу

**Зачем.** Тем, кто хочет выжать из Opus 5 максимум за разумные деньги: правильный effort и режим экономят и токены, и время.

**Как.** Выбор модели: `/model` в сессии, `claude --model claude-opus-5` при старте или дефолт в настройках. Effort: `low` — механика (переименования, импорты), `medium` — дефолт для фич/ревью/агентных задач, `high` — сложный дебаг, миграции, архитектура; стратегия «старт с medium, эскалируй осознанно». Fast-mode ($10/$50, ~2.5× быстрее) — для интерактивной парной работы и живого дебага; стандартный ($5/$25) — для фоновых прогонов.

**Подвох.** Fast-mode дороже вдвое за токен — выгоден по «стоимости секунды» только когда ты реально ждёшь ответ на экране. Статья — сторонний гайд, не офиц. док.

`cost-tokens · workflows` · Источник: [blog/Codersera](https://codersera.com/blog/claude-opus-5-claude-code-guide-2026/)

## 4. /code-review теперь выполняется как фоновый сабагент (Claude Code 2.1.218)

**Зачем.** Тем, кто гоняет автоматическое код-ревью в Claude Code: раньше длинный вывод ревью съедал контекст основной сессии. Теперь он изолирован в фоне.

**Как.** Обнови до 2.1.218+. `/code-review` автоматически исполняется фоновым сабагентом, целью ревью остаются накопленные (stacked) slash-команды. Заодно починили порядок permission-промптов, вставку многострочного текста и точность отчёта о контексте.

**Подвох.** Отдельный фикс критичен для Windows: пути с сегментами вида `C:\Users\unicorn` (начинающиеся на `\u`) раньше превращались в иероглифы CJK в аргументах инструментов — обнови, если ты на Windows.

## 5. Claude Code 2.1.216: отключаемая изоляция ФС и фикс тормозов длинных сессий

**Зачем.** Тем, кто гоняет долгие/безнадзорные прогоны и автоматизацию: изоляция ФС иногда мешает, а длинные сессии раньше тормозили всё сильнее к концу.

**Как.** Настройка `sandbox.filesystem.disabled` пропускает изоляцию файловой системы, оставляя контроль сетевого egress (удобно, когда нужен доступ к диску, но не к сети). Отдельно починили квадратичный по числу ходов рост стоимости нормализации сообщений (многосекундные стопы и медленный resume) и auto-mode, отклонявший команды с ошибкой «HTTP 401» после ротации OAuth-токена.

**Подвох.** Отключая изоляцию ФС, ты снимаешь защитный слой — делай это осознанно и только там, где доверяешь тому, что запускает агент.

## 6. Claude Code Hooks: практический гайд с 20+ готовыми конфигами

**Зачем.** Тем, кто хочет заставить Claude Code автоматически форматировать код, блокировать опасные операции и слать уведомления — без ручного контроля каждого шага.

**Как.** Хуки — shell-команды, срабатывающие на события: `PreToolUse`/`PostToolUse`, `UserPromptSubmit`, `Notification`/`PermissionRequest`, `Stop`/`SubagentStop`, `PreCompact`/`SessionStart`/`SessionEnd`. Кладутся в `.claude/settings.json` (проект) или `~/.claude/settings.json` (глобально). Примеры: PostToolUse + matcher `Write` → `python -m black .` (автоформат); PreToolUse-валидатор, блокирующий правки по путям вроде `/etc/` через `exit 2`; уведомления по важности файла.

**Подвох.** Статья изначально от января 2026, обновлена 22 июля — часть примеров вечнозелёная, сверяйся с актуальным форматом settings.json. Хук с `exit 2` останавливает Claude — не переусердствуй, иначе агент встанет.

`hooks` · Источник: [blog/DataCamp](https://www.datacamp.com/tutorial/claude-code-hooks)

## 9. MCP rug-pull: «безопасный» инструмент становится вредоносным после одобрения

**Зачем.** Тем, кто подключает сторонние MCP-серверы: одобрение инструмента один раз не гарантирует, что он останется безопасным — описан сценарий «rug-pull», когда поведение меняется после того, как ты доверился.

**Как.** Практика защиты: не одобрять MCP-инструменты «навсегда» вслепую, пиновать версии и источники, ограничивать права и сеть (в Claude Code — `sandbox.network.strictAllowlist`), периодически пересматривать, что реально делает сервер.

**Подвох.** Пост обзорный — конкретные PoC и меры даны по верхам, глубину защиты придётся достраивать самому. Тема пересекается с прежними находками про MCP-безопасность.
