## 1. Hallmark — навык дизайна для Claude Code против «AI-выглядящих» интерфейсов

**Зачем.** Если Claude Code делает вам лендинги/интерфейсы, но они выглядят шаблонно (одинаковые градиенты, «карточки-карточки»), Hallmark задаёт стиль и отсекает штампы. Полезно фрилансерам и небольшим командам, которым нужен приличный дизайн без дизайнера.

**Как.** Установить как навык: `npx skills add nutlope/hallmark` (или скопировать файлы в `~/.claude/skills/hallmark/`). Режимы: по умолчанию строит новый UI; `hallmark audit` оценивает существующий код по анти-паттернам; `hallmark redesign` переделывает, сохраняя тексты и брендинг; `hallmark study` вытягивает «ДНК» дизайна со скриншота или URL. Внутри ~57 проверок на «слоп». Автор — Together AI (Nutlope), MIT.

**Подвох.** Это про вкус и структуру, а не про уникальную графику — генерации всё равно нужен ваш контроль. Навык свежий; «57 gate» — маркетинговая формулировка, результат зависит от промпта и компонентной базы проекта.

`skills · tips` · Источник: [github/Nutlope (Together AI)](https://github.com/Nutlope/hallmark)

## 2. Qarinah — сжатая «память проекта» для Claude Code, экономит контекст-токены

**Зачем.** Claude Code дорого «перечитывает» большой проект каждую сессию. Qarinah даёт агенту не всю историю, а короткий выверенный пакет только по нужной теме — это режет счёт за input-токены. Полезно тем, кто быстро жжёт лимиты на больших репозиториях.

**Как.** `npm install --save-dev qarinah`, затем `npx qarinah init .` и запрос вида `npx qarinah query "тема" --minimum-coverage direct --format markdown`. Есть готовые плагин-рантаймы и хуки под Claude Code и Codex. По бенчмаркам автора — 442 113 → 5 682 токена (~98,7% экономии) на тестовых задачах.

**Подвох.** Нужен Node.js 22/24/26; редактирование в content-режиме «не может доказать, что в выводе нет секрета»; работает только по явному opt-in workspace. Цифры экономии — от автора, независимо не проверялись.

`cost-tokens · skills` · Источник: [github/AjnasNB](https://github.com/AjnasNB/qarinah)

## 3. ThumbGate — хук-страж PreToolUse: блокирует утечки секретов и опасные команды

**Зачем.** Агент иногда повторяет одни и те же опасные действия (снести файлы, force-push, светануть ключ). ThumbGate ставит детерминированный барьер на событии PreToolUse — полезно, если вы даёте Claude Code больше автономии и боитесь «сюрпризов».

**Как.** `npx thumbgate init --agent claude-code`; правила добавляются командами вроде `npx thumbgate capture down "Never run DROP on production tables"`; дашборд — `npx thumbgate dashboard --open`. Решения принимаются без LLM на пути проверки (паттерны + опц. локальные эмбеддинги).

**Подвох.** Бесплатный тариф ограничен (2 «захвата» правил в день, до 10 всего, 3 активных правила); дашборд, экспорт правил и history-recall — в Pro за $19/мес. Командной синхронизации пока нет.

`hooks · automation` · Источник: [github/IgorGanapolsky](https://github.com/IgorGanapolsky/ThumbGate)

## 4. Wrap — навык Claude Code, который говорит, можно ли безопасно закрыть сессию

**Зачем.** Перед закрытием терминала легко забыть незакоммиченное/недоделанное. Wrap даёт быстрый чек «безопасно ли выходить» — удобно тем, кто ведёт много коротких сессий за день.

**Как.** Локально: `git clone https://github.com/ravsau/wrap.git && cd wrap && ./install.sh`, затем `/wrap`. Через маркетплейс: `/plugin marketplace add ravsau/wrap` → `/plugin install wrap@saurav-claude-tools` → `/reload-plugins` → `/wrap:wrap`. На выходе — вердикт STOP/CONTINUE и список «висящих хвостов».

**Подвох.** Смотрит только текущий диалог — не сканирует бэклог, другие сессии и не придумывает новые задачи. Репозиторий маленький (6 коммитов), навык узкий.

`skills · workflows` · Источник: [github/ravsau](https://github.com/ravsau/wrap)

## 5. Claude Code хранит транскрипты сессий локально 30 дней — как настроить

**Зачем.** Многие не знают, что переписки с агентом лежат локально в plaintext. Это важно для приватности и для тех, кто работает с чувствительным кодом на общей машине.

**Как.** По доке Anthropic: клиент Claude Code хранит транскрипты в `~/.claude/projects/` 30 дней по умолчанию; период правится ключом `cleanupPeriodDays`. Там же — серверный retention (Consumer без обучения 30 дней / с обучением 5 лет; Commercial 30 дней, есть Zero Data Retention для Enterprise) и как отключать телеметрию (`DISABLE_TELEMETRY`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`).

**Подвох.** Локальное хранение — plaintext: на общей/рабочей машине это потенциальная утечка. ZDR доступен не всем (только квалифицированным Enterprise-аккаунтам).

`tips` · Источник: [docs/Anthropic](https://code.claude.com/docs/en/data-usage)

## 6. 5dive — «компания» агентов Claude Code/Codex на своём сервере (systemd + Telegram)

**Зачем.** Если хочется гонять несколько агентов параллельно «как команду» на своём железе, без облака и фреймворков. Подходит для длительных фоновых задач с ручным контролем через мессенджер.

**Как.** `curl -fsSL https://install.5dive.ai | sudo bash`, затем `sudo 5dive init` (интерактивно спарит агентов с Telegram-ботами). Ручное создание: `sudo 5dive agent create my-agent --type=claude --channels=telegram`. Оркестратор — сама ОС: systemd, journald, Unix-права и общий доступ к ФС вместо брокера.

**Подвох.** Только Linux с systemd (реком. Ubuntu 22.04+), нужен root; каждому агенту — своя подписка/ключ провайдера. Вне systemd — только через Docker.

`subagents · workflows · automation` · Источник: [github/5dive-ai](https://github.com/5dive-ai/5dive)

## 8. ai-config-sync-manager — двусторонняя синхронизация конфигов Claude Code ↔ Codex

**Зачем.** Кто использует и Claude Code, и Codex, вручную поддерживает две конфигурации. Инструмент делает непрерывный двусторонний sync и наглядно показывает, где они разошлись. Полезно командам на двух агентах.

**Как.** `npm install -g ai-config-sync-manager`, далее `ai-config-sync connect` → `ai-config-sync status` → `ai-config-sync sync --apply` (без `--apply` — сухой прогон, пишет с бэкапами). Команда `board` рисует автономный HTML-инвентарь: зелёное — синхронно, красное — конфликт, синее/фиолетовое — только на одном хосте.

**Подвох.** Симлинк-навыки не поддерживаются; SDK-примитивы TaskCreate/TaskUpdate/TeamCreate вырезаются (в Codex нет аналогов); память/рантайм-состояние вне зоны; программного API нет — только CLI.

`automation · tips` · Источник: [github/slash9494](https://github.com/slash9494/ai-config-sync-manager)
