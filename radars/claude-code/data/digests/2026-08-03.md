## Анонс

Главное за день — официальный бета-плагин **Claude Security** (мультиагентный сканер уязвимостей прямо в сессии). Дальше — инструменты вокруг оркестрации агентов (clayrune, TerMinal), навыки и слэш-команды (vibestack), память между Claude Code и Codex (Wienerdog), MCP (новый v2 SDK, orangepro-mcp для грунтованных тестов), гигиена кода (CCN) и наблюдаемость (coralline). Замыкают подборку два кейса-сборки «своими руками».

Заметки честности: свежие записи официального ченджлога (v2.1.214–2.1.219, 18–25 июля) в окно попадают, но **уже опубликованы в прошлых днях** — сегодня не дублируем. Отдельных свежих кейсов именно малого бизнеса за окно почти не нашлось (сильные истории — за май, вне окна), поэтому на последних позициях — конкретные hands-on демки сборки, а не бизнес-истории с цифрами.

## 1. Anthropic выпустила плагин Claude Security — мультиагентный сканер уязвимостей в терминале

**Зачем.** Разработчику или команде, которой нужно прогнать security-ревью прямо из сессии Claude Code — по всему коду или только по diff перед коммитом.

**Как.** `/plugin install claude-security@claude-plugins-official` → `/reload-plugins` → `/claude-security` (меню: скан всего кода / изменений / генерация патчей). Уровень усилий low→max регулирует глубину. Находка попадает в отчёт только пройдя «панель из трёх агентов» (достижимость / влияние / защиты): 2 из 3 → med, единогласно → high.

**Подвох.** Бета. Патчи не применяются автоматически — ревью руками. Мультиагентный скан жжёт токены (инвентаризация, threat modeling, research, adversarial-верификация, опц. red-team).

`skills · subagents` · Источник: [blog / MarkTechPost](https://www.marktechpost.com/2026/07/22/anthropic-releases-claude-security-plugin-for-claude-code-in-beta-a-multi-agent-vulnerability-scanner-that-runs-in-your-terminal/)

## 2. clayrune — единый дашборд для оркестрации нескольких агентов Claude Code по проектам

**Зачем.** Фрилансеру/малой команде, которая гоняет Claude Code сразу в нескольких репозиториях и теряет нить: где какой агент, что запланировано, что готово.

**Как.** Windows: `iwr https://clayrune.io/install.ps1 -useb | iex`. Из исходников: `git clone https://github.com/ronle/clayrune.git && cd clayrune && pip install -r requirements.txt && python app.py` (или `python server.py` → localhost:5199). Диспатч задач, стриминг, память между запусками, синк GitHub Issues, расписание once/daily/interval/cron.

**Подвох.** Нужна своя подписка Claude (CLI, не API); машина должна быть включена для фоновых агентов; хранилище — локальные JSON; фичи удалённого доступа (mc_remote/mc_tunnel) проприетарны.

`subagents · automation` · Источник: [github / ronle](https://github.com/ronle/clayrune)

## 3. vibestack — переносимый набор навыков и слэш-команд для Claude Code (и не только)

**Зачем.** Тем, кто устал промптить одно и то же: готовые процессы для TDD, ревью перед мержем, дебага, security-аудита (OWASP Top 10), брейншторма в дизайн-док.

**Как.** `git clone https://github.com/timurgaleev/vibestack ~/.claude/skills/vibestack` → `~/.claude/skills/vibestack/install`. Команды: `/ship` (мерж→тесты→ревью→bump→PR), `/plan-eng-review`, `/tdd`, `/review`, `/cso`, `/office-hours`.

**Подвох.** «Жёсткие блоки» (/careful, /freeze, /guard) работают только в Claude Code; в Cursor/Kiro — мягкие подсказки. Совместимость по агентам разная (docs/agent-skills-compatibility-audit.md).

`skills · slash-commands` · Источник: [github / timurgaleev](https://github.com/timurgaleev/vibestack)

## 4. Wienerdog — общая память и самообучающиеся навыки для Claude Code и Codex

**Зачем.** Тем, кто переключается между Claude Code и Codex и теряет контекст, и хочет, чтобы агент со временем «запоминал», как вы работаете.

**Как.** macOS/Linux: `curl -fsSL https://raw.githubusercontent.com/wienerdog-ai/wienerdog/main/install.sh | bash`; Windows: `irm .../install.ps1 | iex`; или `npx wienerdog@latest init`. Затем перезапуск Claude Code и `/wienerdog-setup`. Ночное «дозревание» промотит важное в долгую память и лепит навыки из повторов.

**Подвох.** Версия 0.x — форматы поменяются. Зачистка секретов «best-effort». Изоляции на уровне ОС нет: всё под вашим пользователем читает файлы Wienerdog.

`skills · tips` · Источник: [hn / thegyula](https://github.com/wienerdog-ai/wienerdog/)

## 5. Как собрать MCP v2-сервер на TypeScript на новом MCP SDK

**Зачем.** Тем, кто пишет свой MCP-сервер для Claude Code и хочет перейти на v2 SDK (после спецификации MCP от 2026-07-28): меньше кода, деплой на serverless/edge.

**Как.** `npx @agentailor/create-mcp-server@0.7.0 --name=fetch-mcp-server`. Зависимости: `@modelcontextprotocol/server` v2+, `zod` v4.2+ (схемы через `z.object({...})`), `express` v5.2+. Вход — фабрика: `const handler = createMcpHandler(() => getServer())`. Нужен Node 22.19+.

**Подвох.** Ломающие изменения относительно v1: другие импорты, обязательная обёртка zod, убраны GET/DELETE-роуты и ветвления по session-id. Старые v1-серверы переписывать.

`mcp` · Источник: [blog / ialijr](https://dev.to/ialijr/build-an-mcp-v2-server-in-typescript-with-the-new-mcp-sdk-567j)

## 6. orangepro-mcp — MCP-сервер, что строит карту поведения кода и генерит обоснованные тесты

**Зачем.** Командам, которым Claude Code генерит тесты «на глаз»: здесь тесты грунтуются на реальном коде и ранжируются по риску непокрытых поведений.

**Как.** `npm install -g @orangepro/orangepro-mcp` или `npx -y @orangepro/mcp-server@latest start . --prompt-version v5`. Подключение: `npx -y @orangepro/mcp-server@latest agent --client claude-code` → в `.mcp.json`/`~/.claude.json`. Тесты в `orangepro_generated/`, исходники не трогаются.

**Подвох.** Сначала «Dynamically Proven 0» — норма (proof требует прогона против мутаций). Генерация+proof только для TS/JS, Python, Go, Java; остальные языки — лишь статический разбор.

`mcp · testing` · Источник: [github / OrangeproAI](https://github.com/OrangeproAI/orangepro-mcp)

## 7. Видео: как инженеры Anthropic по-новому промптят Claude Code

**Зачем.** Тем, кто хочет подтянуть промптинг под Claude Code, глядя на приёмы «изнутри» Anthropic, а не общие советы.

**Как.** Видеоразбор (канал Duncan Rogoff | Learn Claude Code). Смотреть ради конкретных формулировок задач, работы с планом и ограничениями; переносить в свои сессии.

**Подвох.** Видео без текстовой расшифровки — конкретика в ролике; точные тезисы в карточке не приводим, чтобы не выдумывать. Канал образовательный, не официальный Anthropic.

`prompting · tips` · Источник: [youtube / Duncan Rogoff](https://www.youtube.com/watch?v=r8ih5HRRLLU)

## 8. CCN (Comment Nuker) — вычищает комментарии-мусор, которые ИИ оставил в коде

**Зачем.** Тем, у кого после vibe-кодинга код зарос болтливыми ИИ-комментариями и служебным спамом.

**Как.** `npm install -g commentnuker`, затем `ccn` (меню), `ccn ./src`, `ccn ./src --lang python`. После каждого удаления файл ре-парсится и правка откатывается, если сместился хоть один токен.

**Подвох.** Linux/macOS — ок, Windows под вопросом. Не-JS языки скачивают грамматики при первом запуске. Лицензия source-available (не OSI): для коммерции — отдельная лицензия.

`refactoring · tips` · Источник: [hn / jonhardwickspec](https://github.com/jonhardwick-spec/ccn)

## 9. coralline — статуслайн в стиле Powerlevel10k для Claude Code

**Зачем.** Тем, кто хочет видеть в одной строке остаток контекста и лимитов, стоимость сессии и что делают сабагенты.

**Как.** Проще попросить Claude: `Please install coralline for me: fetch https://raw.githubusercontent.com/Nanako0129/coralline/main/INSTALL.md and follow the playbook in it` — он проведёт «интервью» и поставит. Напрямую (bash): `curl -fsSL .../install.sh | bash`. Датчики: зелёный→жёлтый(50%)→красный(75%).

**Подвох.** Нужен Nerd Font и `jq` (bash) либо PowerShell 5.1 (Windows). Git опционально. Это наблюдаемость, а не изменение поведения агента.

`tips · ide-integration` · Источник: [github / Nanako0129](https://github.com/Nanako0129/coralline)

## 10. TerMinal — локальная «фабрика» для Claude Code с автономным build-loop и наблюдаемостью

**Зачем.** Соло-разработчику/малой команде, которой мало «голого» терминала: видеть расход токенов и статус по сессиям и запускать агентов автономно.

**Как.** Нужны `bun` и `claude`/`codex` в PATH. `git clone https://github.com/trevormil/TerMinal.git && cd TerMinal && bun install && bun run dev` (или `.dmg` из releases). Цикл: агент заводит тикет → работает в отдельном worktree → открывает PR; мерж в main — только человек. Расписание — launchd / systemd / Kubernetes-таймеры.

**Подвох.** Только macOS (Apple Silicon; на Linux — без локального планировщика). Приложение не подписано. Мерж намеренно закрыт для агентов.

`automation · subagents` · Источник: [github / trevormil](https://github.com/trevormil/TerMinal)

## 11. claude-account — переключение между аккаунтами Claude Code без повторного логина

**Зачем.** Тем, у кого несколько аккаунтов/подписок Claude (личный/рабочий) и надоело перелогиниваться при переключении.

**Как.** Скачать релиз, сверить SHA256, `./claude-account install`, добавить `export PATH=...` в `~/.bashrc`. Дальше: `claude account add work`, `claude account use work`, `claude account list`, `claude account current`.

**Подвох.** Только Linux; сборка из исходников — Rust 1.85+. Кредов не хранит (аутентификация за Claude Code), вычищает `ANTHROPIC_API_KEY` ради изоляции. Неофициальный community-проект.

`tips` · Источник: [hn / hamza_rehman](https://github.com/hamzarehmandeveloper/claude-account)

## 12. В маркетплейсе плагинов Claude Code нет поля цены — и это осознанный дизайн

**Зачем.** Авторам плагинов и тем, кто прикидывает бизнес-модель вокруг экосистемы Claude Code.

**Как.** Вывод: монетизация — только через отдельный SaaS-бэкенд, к которому плагин аутентифицируется (модель сервисная, не продуктовая). Пользователю: установка плагина = постоянные расходы в токенах, а не разовая покупка → чистить неиспользуемое.

**Подвох.** Это анализ автора, а не анонс Anthropic. Вывод шире: конфиг-артефакты стабильно бесплатны, платят за «спроектированные» продукты.

## 14. Кейс: пустыня в одном HTML-файле, собранная с Claude Code

**Зачем.** Фрилансеру/соло-мейкеру как пример, что рабочую графическую страницу можно собрать за один заход в одном файле — легко показать клиенту или повторить.

**Как.** Видео-разбор процесса (канал GoteDev): Claude Code генерит и итеративно правит один HTML (canvas/WebGPU) до готовой сцены.

**Подвох.** Это демо/шоукейс, не бизнес-кейс с цифрами — ценно как приём и вдохновение. Исходник и метрики в карточке не приводятся.
