## 1. Claude Code 2.1.237: стиль «Кратко» в /config и фикс кэша промптов для gateway

**Что нового.** Версия 2.1.237 от 20 августа 2026. Добавлен встроенный стиль «Concise» («Кратко»): Claude сразу выдаёт результат без преамбул — сама работа остаётся тщательной. **Как попробовать.** Обновите: npm install -g @anthropic-ai/claude-code. Стиль «Кратко»: /config → Output style → Concise. Фикс кэша работает автоматически после обновления.

## 2. Claude Code 2.1.236: ANTHROPIC_DEFAULT_MODEL и уведомление когда агент освобождается

## 3. IT-конференция на 600 участников: рассылка уникальных ссылок — с 8 ч/день до 30 минут

**Бизнес.** Команда IT-конференции «Conversations» (Just AI), 500–700 участников, дважды в год. Корпоративная аудитория: банки, госструктуры с жёсткими почтовыми фильтрами.

**Процесс.** Персональная рассылка каждому участнику: уникальный конференционный ID + ссылка на трансляцию. Участники регистрируются из разных источников в разные сроки.

**Было.** До 8+ часов ручной работы в день перед конференцией. 30% писем не доходило до корпоративных адресатов (банки, госструктуры). 30+ обращений в поддержку ежедневно с просьбой переслать ссылку.

**Сделали.** Три блока автоматизации на Just AI Agent Platform: синхронизация участников из Google Sheets; присвоение уникального ID; отправка через личный SMTP пакетами (обходит корпоративные фильтры).

**Стало.** Ручная работа: 30 мин/день (минус 94%). Доставляемость: 95%+ (было 70%). Поддержка: единицы обращений (было 30+/день). Спам-rate: менее 3%. Экономия на альтернативном решении: около 50 000 руб.

**Инструменты.** Just AI Agent Platform — детерминированный воркфлоу без LLM и без затрат токенов. Google Sheets API. Личный SMTP-домен с SPF/DKIM.

**Как повторить.** 1) Список участников в Google Sheets. 2) Блок синхронизации через API. 3) UUID для каждого участника. 4) SMTP-рассылка пакетами 50–100 писем/час. 5) SPF, DKIM, DMARC обязательны.

**Подвох.** Без DNS-записей SPF/DKIM письма попадут в спам. Рассылка 600 писем по 100/час занимает 6 часов. Инструмент (Just AI) закрытый, стоимость не раскрыта.

## 4. COD-магазин одежды (Марокко): подтверждение заказов в WhatsApp — с 60% до 88%, плюс $4 500/нед

**Бизнес.** Марокканский интернет-магазин женской одежды, модель Cash on Delivery. В COD-e-commerce клиент подтверждает заказ до отгрузки — без подтверждения посылка возвращается со 100% убытком на логистику.

**Процесс.** Подтверждение каждого нового заказа: сообщение клиенту с деталями и запросом подтверждения. Ключевой показатель — confirmation rate.

**Было.** Ручные звонки операторов по каждому заказу. Confirmation rate: 60–70%. Непринятые посылки — прямые убытки: оплата доставки плюс возврат товара.

**Сделали.** WhatsApp-бот отправляет сообщение с деталями заказа (фото товара, цена, адрес) и кнопками «Подтвердить» / «Отменить». Если ответа нет через 2 часа — повторный контакт.

**Стало.** Confirmation rate: 88% (+18–28 п.п.). Дополнительная выручка от восстановленных заказов: $4 500 в неделю.

**Инструменты.** WhatsApp Business API плюс чат-бот. Конкретный провайдер в источнике не указан; типовые: WATI, Respond.io, 360dialog.

**Как повторить.** 1) Подключить WhatsApp Business API. 2) Триггер на новый заказ — сообщение с фото + кнопки. 3) Повтор если нет ответа за 2 ч. 4) Интегрировать статус в систему склада.

**Подвох.** WhatsApp Business API платный. В РФ Telegram-боты дешевле покрывают ту же задачу. Без персонализации конверсия ниже. Нужна интеграция с OMS.

## 5. D2C-бренд добавок: AI-бот для WISMO-запросов — ответ за 3 секунды вместо 6 часов

**Бизнес.** D2C-бренд спортивных добавок, прямые продажи через сайт. 250+ обращений в поддержку ежедневно — по статусам заказов.

**Процесс.** Обработка WISMO-запросов (Where Is My Order): «Где мой заказ?», «Когда доставка?», «Дайте трек-номер». Однотипные вопросы с однозначными ответами.

**Было.** 250+ запросов/день. Среднее время первого ответа: 6 часов. Команда тратила большую часть дня на статусы вместо сложных проблем.

**Сделали.** AI-бот обрабатывает WISMO в чате: запрашивает номер заказа, подтягивает статус из трекинга, отвечает немедленно. Нестандартные случаи передаёт оператору.

**Стало.** Среднее время ответа: 3 секунды (минус 99.9%). Высвобождено 4 ч/день рабочего времени команды.

**Инструменты.** AI-чатбот с интеграцией в трекинг-систему. В источнике не указан; типовые: Gorgias AI Agent, Tidio AI, Freshdesk Freddy.

**Как повторить.** 1) Выгрузить топ обращений — WISMO обычно первый. 2) Подключить чатбот к API службы доставки. 3) Скрипты ответов с подстановкой статуса. 4) Через 2 недели — замерить долю автоответов.

**Подвох.** Если трекинг даёт устаревшие статусы — бот дезинформирует клиентов. Нужна граница: что решает бот, что эскалирует. В пики нетипичных запросов станет больше.

## 6. Shopify-магазин одежды: AI-поддержка вместо 3 операторов — 76% тикетов закрывает ИИ, $8 000/мес

**Бизнес.** Интернет-магазин одежды на Shopify. 400 тикетов в поддержку еженедельно. Команда: 3 оператора полный день.

**Процесс.** Входящие обращения: статусы заказов, политика возвратов, вопросы по размерам, наличие. Большинство — однотипные с однозначными ответами.

**Было.** 400 тикетов/нед, 3 оператора. Среднее время ответа — несколько часов. Рутина занимала всё рабочее время вместо сложных случаев.

**Сделали.** AI-агент обрабатывает типовые запросы автономно, сложные или эмоциональные эскалирует оставшемуся оператору. База знаний: FAQ, политика возвратов, таблицы размеров.

**Стало.** 76% тикетов закрывает AI. Команда: 3 оператора → 1 оператор плюс AI. Экономия: $8 000/мес.

**Инструменты.** AI helpdesk для e-commerce (конкретный не указан; типовые: Gorgias AI Agent, Richpanel, Tidio AI).

**Как повторить.** 1) Классифицировать тикеты по типам. 2) Выделить сценарии с однозначным ответом (60–80%). 3) Составить базу знаний. 4) Запустить AI в режиме human-in-the-loop. 5) Через 2 недели расширить охват.

**Подвох.** 76% автономности требует качественной базы — без неё бот даёт неточные ответы. В сезоны доля нетипичных обращений растёт. Настройка базы занимает 2–4 недели.

## 7. Ювелирный интернет-магазин: WhatsApp-воронка брошенных корзин — $18 400 за 30 дней

**Бизнес.** Ювелирный интернет-магазин (e-commerce, средний чек выше среднего — покупка требует обдумывания).

**Процесс.** Возврат клиентов, добавивших товары в корзину но не оплативших. Причины: отвлеклись, засомневались в размере, хотели посоветоваться.

**Было.** Стандартные email-напоминания с низкой открываемостью. Большинство потенциальных покупок терялось.

**Сделали.** WhatsApp-воронка: через 1 час после брошенной корзины — персональное сообщение с фото товара. Если нет ответа — повтор через 24 часа. Диалог ведёт бот, вопросы передаёт консультанту.

**Стало.** $18 400 восстановленной выручки за 30 дней. ROI: 12× на стоимость автоматизации.

**Инструменты.** WhatsApp Business API плюс чат-бот для e-commerce (конкретный в источнике не указан).

**Как повторить.** 1) Webhook на брошенную корзину (Shopify/WooCommerce). 2) Через 1 ч — WhatsApp с фото товара. 3) Через 24 ч — повтор без ответа. 4) Живой консультант для сомневающихся. 5) В РФ — Telegram-бот покрывает ту же логику.

**Подвох.** Более 3 касаний за сутки снижают лояльность. WhatsApp Business API требует одобрения Meta. Для дорогих товаров важнее качество диалога, чем скорость.
