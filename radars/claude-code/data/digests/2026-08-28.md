## 1. Claude Code 2.1.247: SendFeedback, /claude-api cost-optimize и фикс нелатинских раскладок

**Что нового.** Версия 2.1.247 (26 августа 2026). Новые функции: `SendFeedback` — инструмент, который при обращении к поддержке автоматически формирует отчёт с контекстом сессии; `/claude-api cost-optimize` — команда профилирует API-расходы проекта и предлагает конкретные оптимизации; `spinnerTipsOverride` — настройка собственных подсказок на экране ожидания; автоматическое окно компактификации у Sonnet 5 изменено на полный контекст 1M. Расширено покрытие Admin API в навыке `/claude-api`. Ключевые исправления: быстрые нажатия клавиш-стрелок больше не действуют на неверную строку истории; субагенты, упавшие на ошибке 404 модели, теперь используют цепочку запасных моделей; **исправлены Ctrl-шорткаты под нелатинскими клавиатурными раскладками** (кириллица, арабский, греческий); пофиксен вывод mouse reports при разбивке по буферам; устранены проблемы с /rename и тихим подтверждением.

**Зачем вам.** Фикс нелатинских раскладок особенно важен для русскоязычных пользователей: Ctrl+C/Ctrl+V и навигационные шорткаты наконец работают корректно без переключения раскладки. `/claude-api cost-optimize` экономит время при отладке дорогих автоматизаций — покажет, где именно «утекают» токены. `SendFeedback` ускоряет обращения в поддержку: не нужно вручную копировать логи.

**Как попробовать.** `claude update` до 2.1.247. Ctrl-шорткаты работают автоматически. `/claude-api cost-optimize` — в любой рабочей сессии проекта, использующего Anthropic API. `SendFeedback` доступен как инструмент в агентных сессиях.

`новости-claude · релиз · возможности` · Источник: [Anthropic](https://code.claude.com/docs/en/changelog)

## 2. Claude in Chrome: общая доступность — автономные действия в браузере и защита от инъекций

**Что нового.** 26 августа 2026 года Anthropic объявил об общей доступности Claude in Chrome на всех платных планах (Pro, Max, Team, Enterprise). Ключевые возможности: (1) **Автономные действия** — Claude теперь сам выполняет цепочки браузерных действий без запроса одобрения на каждый шаг; (2) **Классификатор безопасности** — перед каждым действием проверяет соответствие оригинальному запросу; (3) **Защита от prompt injection** — специальные пробы сканируют содержимое страниц на атаки до начала действий; (4) Поддержка чтения страниц, ввода текста, кликов, навигации и заполнения форм с использованием существующих учётных данных пользователя. Доступ к внутренним дашбордам, легаси-системам и вендорским порталам без нативных интеграций.

**Зачем вам.** Прежде всего — автоматизация рутины в браузере без API: загрузить отчёт из внутреннего дашборда, заполнить форму в корпоративной системе, перенести данные между вкладками. Особенно ценно там, где API нет или закрыт — устаревшие ERP, CRM без OAuth, любые порталы. Год назад требовалось одобрение каждого действия; теперь можно описать задачу и отойти.

**Как попробовать.** Установить расширение Chrome Web Store. Корпоративные администраторы управляют доступом через Organization Settings (можно ограничить до доверенных доменов). Ограничения: только Chrome, не другие Chromium-браузеры; мобильных платформ нет; работа с файлами и другими приложениями — по-прежнему через десктопное приложение Claude.

`новости-claude · возможности` · Источник: [Anthropic Blog](https://claude.com/blog/claude-in-chrome-generally-available)

## 3. Маркетолог Anthropic автоматизировал еженедельные брифинги для сейлзов через Claude Code

**Что нового.** Пост от 24 августа 2026: Адам Уорд (Anthropic, field marketing) описал, как автоматизировал еженедельные брифинги для торговых представителей с помощью Claude Code без опыта программирования. До автоматизации: каждое воскресенье вечером — ручная сборка PowerPoint из данных нескольких платформ и презентация на Monday stand-up. При росте команды персонализация исчезла, охват стал неравномерным. Что сделал: Claude Code с MCP-подключением к BigQuery (основной источник маркетинговых данных, аггрегирующий HubSpot, Clay, Salesforce) и Slack. Скрипт для каждого сейлза: (1) берёт его территорию из CRM; (2) находит релевантные обновления аккаунтов из Slack; (3) матчит с контент-библиотекой (события, вебинары, блог, партнёры); (4) генерирует персонализированный список из 3 действий; (5) формирует сводку для менеджеров; (6) архивирует каждую рассылку.

**Зачем вам.** Кейс показывает ценность Claude Code для нетехнических профессионалов: маркетолог, а не разработчик, написал продуктивный automation-скрипт. Паттерн «один отчёт → персонализированные рассылки для каждого участника» применим в любой команде с данными в BigQuery/Salesforce и коммуникацией в Slack. Скрипт проработал в отпуск Адама без участия человека.

**Как попробовать.** Установить Claude Code + настроить MCP-подключение к BigQuery или вашей основной базе данных. Начать с одного типа рассылки (например, еженедельный дайджест по сделкам). Описать логику словами в prompt — Claude Code сгенерирует скрипт, протестирует и исправит ошибки в диалоге. Полный гайд в оригинальном посте.

`новости-claude · маркетинг-контент · возможности` · Источник: [Adam Ward / Anthropic Blog](https://claude.com/blog/how-an-anthropic-field-marketer-uses-claude-code-to-send-weekly-personalized-updates-to-every-sales-rep)

## 4. Гайд Anthropic для стартапов: 5 принципов внедрения Claude Code — ClickHouse, Clay, Artemis

**Что нового.** 20 августа 2026: Anthropic опубликовал «The Claude Code Guide for Startups» — пять принципов, дистиллированных из 12+ реальных деплоев. Принципы: (1) **Everyone Ships** — нетехнические сотрудники создают рабочие функции; (2) **Automate the Tedium** — агенты берут механические 80% задач, люди — суждения; (3) **Trust, but Verify** — мониторинг и верификация обязательны при автоматизации; (4) **Build for Rebuilding** — решения временны, модели быстро улучшаются; (5) **Prototype, Dogfood, Productionize** — внутренние AI-инструменты кормят продуктовые решения. Реальные метрики компаний: **ClickHouse** — +30% фич, агенты для flaky-тестов и покрытия тестами заняли 2-е и 3-е место по вкладу в репозиторий; **Clay** — 100% триажа багов автоматизировано; **Omni** — 2–3x производительность инженеров; **Artemis Security** — 6000+ PR в неделю, компания считает себя «AI-native».

**Зачем вам.** Если вы думаете о том, как встроить Claude Code в рабочие процессы команды, — это структурированный старт. Принцип «Build for Rebuilding» особенно важен: не архитектурьте на годы, модели обесценивают решения. Принцип «Everyone Ships» — сигнал, что вкладываться стоит в обучение нетехнических команд, а не только в найм инженеров.

**Как попробовать.** Полный гайд на claude.com/blog/claude-code-guide-for-startups. Практический старт: (1) подключить Claude Code к существующим инструментам через MCP или CLI; (2) создать библиотеку навыков команды в .claude/skills/; (3) добавить CLAUDE.md с архитектурными правилами; (4) настроить evals для отслеживания регрессий; (5) тестировать перестройки через git worktrees.

## 5. Строительная компания: интеграция формы с AmoCRM — заявка за 30 секунд вместо 40 минут

**Бизнес.** Строительная компания — жилая и коммерческая недвижимость, Россия. Несколько активных проектов, менеджеры в отделе продаж.

**Процесс.** Приём заявок с сайта: данные из формы приходили на email, менеджер вручную вносил их в AmoCRM, назначал ответственного и уведомлял команду в Telegram.

**Было.** Среднее время обработки заявки: 40 минут. Ручной ввод данных → ошибки и дубли. Неравномерное распределение заявок между менеджерами. Опоздавший ответ = потерянный лид в конкурентной нише.

**Сделали.** Интегрировали форму сайта напрямую с AmoCRM через API: заявка создаётся автоматически при отправке формы. Добавили умное распределение по менеджерам с учётом загрузки. Подключили Telegram-уведомления о новой заявке в реальном времени. Настроили мониторинг через Grafana.

**Стало.** Время обработки заявки: 40 мин → 30 секунд (–98,75%). Конверсия: +28%. Ошибки при вводе данных: –95%. Скорость реакции команды: +75%. Заявки больше не теряются.

**Инструменты.** AmoCRM (CRM), Telegram Bot API (уведомления), Grafana (мониторинг), Python + Django (интеграционный слой), QU Bot (разработчик решения).

**Как повторить.** 1) Подключить форму сайта к CRM через webhooks или API (для AmoCRM — есть официальный API). 2) Добавить логику распределения заявок по менеджерам (round-robin или по загрузке). 3) Настроить Telegram-бот для мгновенных уведомлений. 4) Grafana или аналог для мониторинга потока. 5) Начать с одного источника заявок, затем подключить остальные.

**Подвох.** Кейс опубликован самим разработчиком (QU Bot) — нет независимой верификации, клиент не назван. Дата публикации в источнике указана как «2026» без конкретного месяца: свежесть в рамках 90 дней не подтверждена. Автоматизация приёма заявок не решает проблему качества самого продукта или маркетинга — конверсия +28% возможна при достаточном объёме входящего трафика.
